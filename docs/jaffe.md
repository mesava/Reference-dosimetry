# Инструменты: график Яффе

Подраздел вкладки «Инструменты» (адрес `#jaffe`) для ввода в эксплуатацию системы камера — кабель — электрометр: по показаниям при ряде напряжений строится график Яффе, находятся показание насыщения M<sub>нас</sub>, поправка на рекомбинацию при рабочем напряжении, напряжение начала умножения заряда V<sub>max</sub>; проверяются метод двух напряжений, полярность и зависимость от дозы за импульс. Расчётное ядро — `src/core/jaffe.js`, интерфейс — `src/ui/jaffe-ui.js` и `src/ui/chart.js` (график в SVG), тесты — `tests/jaffe.test.js`, демонстрационный пример — `src/core/sample-jaffe.js`.

При замене любой части системы (камеры, кабеля, электрометра) график снимают заново. После ввода в эксплуатацию при каждой калибровке достаточно метода двух напряжений на вкладках дозиметрии.

В начале страницы — короткий ответ «Когда / Что делать / Результат». Результат используется и в других местах калькулятора: начальную рекомбинацию C<sub>init</sub> из раздела 5 забирают кнопки «Взять из графика Яффе» в поправках на рекомбинацию по глубине (вкладка «МВ фотоны», раздел 5; «Кривая дозы электронов», раздел 4). Кнопки берут C<sub>init</sub> по дозе за импульс, если он есть, иначе b₀/(n − 1) по ур. 17, а для непрерывного пучка с осью 1/V — k<sub>s</sub> − 1; в разделе 5 у передаваемого значения стоит пометка, а у кнопки после нажатия — откуда взято значение (камера, №, дата). C<sub>init</sub> по дозе за импульс и b₀/(n − 1) — две независимые оценки одной и той же начальной рекомбинации; их расхождение показывает, насколько точна оценка.

## Что вводится

1. **Система и условия:** камера, электрометр, кабель (с заводскими номерами), аппарат, пучок и условия облучения; тип пучка — импульсный, импульсно-сканирующий или непрерывный (⁶⁰Co). Камера выбирается из базы калькулятора (цилиндрические — как на вкладке «МВ фотоны», плоскопараллельные — как на вкладке «Электроны»); если её там нет — «Другая камера» и название вручную. В файлах, сохранённых до появления списка, название подбирается по базе (например, «PTW 30013»), а если не найдено — остаётся своим текстом.
2. **Напряжения и линейная область:** напряжение производителя (наибольшее рекомендованное, по желанию), рабочее V₁ и пониженное V₂ (по желанию — для проверки метода двух напряжений). Ось графика: 1/V (импульсные пучки; начальная рекомбинация) или 1/V² (общая рекомбинация в непрерывном пучке). Линейная область — автоматически с допуском (по умолчанию 0,1 %) или вручную.
3. **Показания:** напряжение, показание при обычной полярности и, по желанию, при обратной. Строк сколько угодно, порядок не важен; одно напряжение — одна строка (среднее нескольких измерений).
4. **Разные мощности дозы** (по желанию): для каждого условия (РИП, глубина) — показания M₁ и M₂ при V₁ и V₂ из раздела 2 или готовый k<sub>s</sub>; для ускорителей — и доза за импульс D<sub>pp</sub> (мГр за импульс или в относительных единицах). Отдельно — показание M₁, для которого найти k<sub>s</sub> по ур. 17.

Методика измерений (Report 374, прил. A.5; TRS-398 Rev.1, разд. 4.4.3.4): 6–8 напряжений примерно от трети напряжения производителя до него (TRS-398 — во всём диапазоне до максимума, рекомендованного производителем), той же полярности, что и рабочее; после каждой смены напряжения ждать, пока показания установятся. Дозу за импульс меняют через РИП или глубину, а не через частоту импульсов (Report 374, разд. 4.4.4).

## Как считается

- Для каждой точки x = 1/V (или 1/V²), y = 1/M. В линейной области 1/M = 1/M<sub>нас</sub> + A/V — Report 374, ур. (A.3); для 1/V² — 1/M = 1/M<sub>нас</sub> + B/V², ур. (A.4).
- **Линейная область автоматически** — самый длинный непрерывный по напряжению участок (не меньше трёх точек), на котором все точки отклоняются от прямой не больше допуска, а крайние точки участка (при четырёх точках и больше) — и от прямой, проведённой через остальные его точки: так начало умножения заряда не «растворяется» в аппроксимации. При равной длине выбирается участок с более высокими напряжениями. Вручную — точки, отмеченные в столбце «В прямой»; щелчок по флажку при автоматическом выборе переключает на ручной, сохраняя текущий выбор.
- **Прямая** — метод наименьших квадратов; M<sub>нас</sub> = 1/a, где a — свободный член. Неопределённость M<sub>нас</sub> по разбросу точек — стандартная ошибка свободного члена (для справки).
- **Поправка:** k<sub>s</sub> = M<sub>нас</sub>/M₁ — TRS-398 Rev.1, ур. (15); P<sub>ion</sub> = M<sub>нас</sub>/M — Report 374, ур. (A.2). Берётся показание при V₁ из таблицы; если его нет — значение по прямой, 1 + (b/a)·x(V₁). На графике по вертикали отложено M<sub>нас</sub>/M, поэтому прямая приходит в 1 при 1/V = 0.
- **V<sub>max</sub>** — наибольшее напряжение линейной области. Если выше неё точки лежат под прямой (показания растут быстрее, чем позволяет рекомбинация), это умножение заряда: рабочее напряжение должно быть не выше V<sub>max</sub> и не выше напряжения производителя (TRS-398, сноска 23; Report 374, разд. 4.4.4, прил. A.5). Если точки выше области лежат над прямой (показания ниже ожидаемых), это не умножение заряда — выводится предупреждение о дрейфе.
- **Метод двух напряжений** с теми же V₁ и V₂ — для сравнения с графиком:
  - TRS-398: импульсный и непрерывный пучок с осью 1/V — ур. (13) с табл. 10 (импульсный или импульсно-сканирующий столбец) или ур. (14); непрерывный пучок с осью 1/V² — ур. (16): k<sub>s</sub> = (n² − 1)/(n² − M₁/M₂), n = V₁/V₂;
  - TG-51: P<sub>ion</sub> = (1 − n)/(M₁/M₂ − n) для импульсного пучка, ур. (12); (1 − n²)/(M₁/M₂ − n²) для непрерывного, ур. (11).
  
  Расхождение с графиком больше 0,1 % означает, что при этих напряжениях метод двух напряжений использовать нельзя (TRS-398, разд. 4.4.3.4); V₁/V₂ меньше 2 — предупреждение.
- **Обратная полярность:** та же процедура по показаниям обратной полярности в линейной области; k<sub>s</sub> при V₁ при двух полярностях должен различаться меньше чем на 0,1 % — иначе возможна неполадка камеры (TRS-398, табл. 3, сноска 25; аддендум TG-51, табл. III). Для каждой точки выводится k<sub>pol</sub> = (M + M<sub>обр</sub>)/(2M).
- **Непрерывный пучок, ось 1/V:** k<sub>s</sub> − 1 — начальная рекомбинация; больше 0,2 % — камера не отвечает критериям эталонного класса.
- **Разные мощности дозы (раздел 5):** k<sub>s</sub> каждого условия — методом двух напряжений по формулам протокола (как выше). По условиям с показаниями M₁, M₂ строится прямая M₁/M₂ = (1 + b₀) + b₁·M₁ — **обобщённый подход ди Алмейды и Ниателя** (TRS-398 Rev.1, разд. 4.4.3.4 d, ур. 17): k<sub>s</sub> = 1 + b₀/(n − 1) + b₁·M₁/(n² − 1), для импульсных пучков общий член b₁·M₁/(n − 1); n = V₁/V₂. Свободный член даёт начальную рекомбинацию b₀/(n − 1), наклон — общую; k<sub>s</sub> находится для любого показания M₁ без повторного измерения (например, для каждой глубины кривой или другой мощности дозы). TRS-398 рекомендует этот подход, когда ни 1/M от 1/V, ни от 1/V² не линейны, и когда k<sub>s</sub> нужен при нескольких мощностях дозы. Выводятся b₀, b₁, k<sub>s</sub> при введённом M₁ и при показании раздела 3 (сравнение с графиком имеет смысл, если показания сняты при одинаковом числе МЕ); отклонение точек от прямой пересчитывается в k<sub>s</sub>: (Δ(M₁/M₂))/(n − 1).
- **Доза за импульс (ускорители):** k<sub>s</sub> = 1 + C<sub>init</sub> + C<sub>gen</sub>·D<sub>pp</sub> (аддендум TG-51, ур. 2) — прямая по трём и более условиям с указанной D<sub>pp</sub>. Камера эталонного класса: C<sub>init</sub> < 0,2 %, зависимость линейная (отклонение точек от прямой не больше 0,1 %), наклон положительный (аддендум TG-51, табл. III; TRS-398, табл. 3, п. 1–2).

## Проверки системы

На табло — метка «проверки выполнены», «проверок не выполнено: n» или, если проверки выполнены, но есть предупреждения (например, умножение заряда выше V<sub>max</sub>), «предупреждений: n». Ниже — сводка проверок со статусом «выполнено» / «не выполнено» / «нет данных» и ссылкой на источник:

| Проверка | Критерий | Источник |
|---|---|---|
| Линейность графика в выбранной области | наибольшее отклонение не больше допуска | Report 374, прил. A.5 |
| V₁ в линейной области, не выше V<sub>max</sub> | V<sub>low</sub> ≤ V₁ ≤ V<sub>max</sub> | Report 374, разд. 4.4.4, прил. A.5 |
| V₁ не выше напряжения производителя | V₁ ≤ V<sub>ман</sub> | TRS-398, сноска 23 |
| k<sub>s</sub> при V₁ | ≤ 1,05 | TRS-398, табл. 3 |
| Полярность | \|Δk<sub>s</sub>\| < 0,1 % при V₁. Табл. 3 (п. 5) требует < 0,1 % для разницы поправки на начальную рекомбинацию; при одной дозе за импульс общая рекомбинация при обеих полярностях одна и та же, так что разница k<sub>s</sub> отражает разницу начальной. Сноска 25: заметная разница k<sub>s+</sub> и k<sub>s−</sub> может указывать на неполадку камеры | TRS-398, табл. 3, сноска 25; аддендум TG-51, табл. III |
| Метод двух напряжений | расхождение с графиком ≤ 0,1 % | TRS-398, разд. 4.4.3.4 |
| Начальная рекомбинация | < 0,2 %: ускорители — C<sub>init</sub> по дозе за импульс, а если её нет — b₀/(n − 1) по ур. 17 (три и более условия); ⁶⁰Co — k<sub>s</sub> − 1 при оси 1/V | TRS-398, табл. 3, ур. 17; аддендум TG-51, табл. III |
| Зависимость от дозы за импульс | линейная (отклонение ≤ 0,1 %), наклон положительный — по D<sub>pp</sub> или по ур. 17 | TRS-398, табл. 3; аддендум TG-51, табл. III; Report 374, разд. 4.4.4 |

## График

SVG строится по ширине контейнера (подписи не масштабируются вместе с картинкой) и перерисовывается при изменении ширины. Закрашенные точки вошли в прямую, полые — вне линейной области; квадраты — обратная полярность. Сплошная линия — прямая на линейной области, пунктир — её продолжение до 1/V = 0 и за пределы области. Вертикальные метки — V₁ и V₂. Цвета (токены `--series-1`, `--series-2`) проверены на различимость при нарушениях цветового зрения в светлой и тёмной темах; кроме цвета, серии различаются формой значка. Значения каждой точки — во всплывающей подсказке и в таблице показаний; печать и PDF — в светлых цветах.

## Ограничения

- Калькулятор не определяет «правильный» допуск линейности: 0,1 % — разумное значение при хорошей повторяемости показаний; при большом разбросе область может оказаться короче, тогда точки можно выбрать вручную.
- Если 1/M не линейно ни от 1/V, ни от 1/V², k<sub>s</sub> по графику не определяется: инструмент предупреждает и предлагает обобщённый подход ди Алмейды и Ниателя (раздел 5, ур. 17) или напряжения в линейной области.
- Начальная рекомбинация передаётся кнопками только по нажатию: если график Яффе снят другой камерой, значение у кнопки покажет это (камера, №, дата), но калькулятор не запрещает его взять.
