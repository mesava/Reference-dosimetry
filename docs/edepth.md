# Инструменты: кривая дозы электронов

Подраздел вкладки «Инструменты» (адрес `#edepth`): пересчёт кривой ионизации, измеренной камерой в пучке электронов, в кривую глубинной дозы и параметры пучка — R<sub>50</sub>, R<sub>100</sub>, R<sub>90</sub>, R<sub>80</sub>, R<sub>p</sub>, D<sub>x</sub>, z<sub>ref</sub> и PDD(z<sub>ref</sub>). Результат переносится кнопкой во вкладку «Электроны». Расчётное ядро — `src/core/edepth.js`, интерфейс — `src/ui/edepth-ui.js` (график — `src/ui/chart.js`), тесты — `tests/edepth.test.js`, демонстрационный пример — `src/core/sample-edepth.js` (модельная кривая, вымышленные данные).

## Что вводится

- **Детектор:** ионизационная камера из списка камер для электронов (тот же, что на вкладке «Электроны») или «другая» с типом и радиусом полости / водным эквивалентом окна; либо детектор дозы, если сравнением с камерой подтверждено, что он отвечает дозе и не зависит от мощности дозы; для электронов — неэкранированный диод (Report 385, разд. 4).
- **Глубина в данных:** единицы (мм или см) и сдвиг — по протоколу для камеры, «уже учтён в данных» или вручную.
- **Кривая:** два столбца из экспорта сканера — глубина и показание. Подходят CSV (в том числе с запятой как разделителем), TXT с табуляцией или пробелами, точка с запятой с десятичной запятой и PTW .mcc (берётся первая кривая, блок BEGIN_DATA … END_DATA). Строки без двух чисел (заголовки, комментарии) пропускаются, одинаковые глубины усредняются, порядок строк не важен.

Условия измерения: центральная ось в воде, РИП 100 см, поле на поверхности не меньше 10 × 10 см; предпочтительна плоскопараллельная камера, цилиндрическая — при R<sub>50</sub> > 3 г/см² (TRS-398, разд. 7.3.2, табл. 18). В идеале показания на всех глубинах исправляют на рекомбинацию и полярность; TRS-398 советует снимать кривые при обеих полярностях как быструю проверку системы (разд. 7.3.2). Для поправки на рекомбинацию по глубине доза за импульс на каждой глубине оценивается по дозе за импульс на опорной глубине, пересчитанной по проценту ионизации (сноска 46); в этом инструменте такая поправка пока не вносится.

## Поправки по глубине (по желанию)

TRS-398 Rev.1 (разд. 7.3.2): в идеале показания камеры на всех глубинах исправляют на рекомбинацию и полярность; кривые при обеих полярностях — быстрая проверка системы. В разделе 4 обе поправки включаются отдельно (только для камеры); они вносятся в показания до определения I<sub>50</sub>, а в итогах выводится, насколько они изменили I<sub>50</sub> и PDD(z<sub>ref</sub>) по сравнению с расчётом без них.

- **Рекомбинация.** В импульсных пучках общая рекомбинация пропорциональна дозе за импульс (разд. 4.4.3.4 e), а доза за импульс на глубине — показанию на этой глубине (сноска 46: доза за импульс на каждой глубине оценивается по номинальной дозе за импульс, пересчитанной по проценту ионизации). Поэтому k<sub>s</sub>(z) = 1 + C<sub>init</sub> + (k<sub>s,max</sub> − 1 − C<sub>init</sub>)·M(z)/M<sub>max</sub>, где k<sub>s,max</sub> — поправка на глубине максимума ионизации (метод двух напряжений в тех же условиях), C<sub>init</sub> — начальная рекомбинация, от глубины не зависящая. C<sub>init</sub> можно взять кнопкой из «Графика Яффе» (C<sub>init</sub> по дозе за импульс или b₀/(n − 1) по ур. 17); если не задан — 0, и вся поправка считается общей. Это тот же подход, что и ур. 17 ди Алмейды и Ниателя: k<sub>s</sub> линеен по показанию.
- **Полярность.** Вторая кривая — при обратной полярности, в тех же единицах и при том же числе МЕ (или нормированная так же, как основная: для формы кривой важно только изменение k<sub>pol</sub> с глубиной); k<sub>pol</sub>(z) = (|M₊| + |M₋|)/(2|M|) с линейной интерполяцией второй кривой на глубины первой; вне её диапазона — k<sub>pol</sub> ближайшей точки.

Обычно обе поправки меняют I<sub>50</sub> на сотые доли миллиметра: на спаде доза за импульс меньше, поэтому k<sub>s</sub> там ближе к 1, а k<sub>pol</sub> почти не зависит от глубины. Заметными они становятся при высокой дозе за импульс.

## Как считается

1. **Глубина точки измерения** z = z<sub>данных</sub> + Δ. Сканер записывает глубину опорной точки камеры — центра цилиндрической или наружной поверхности входного окна плоскопараллельной:

   | | TRS-398 Rev.1 | TG-51 + Report 385 |
   |---|---|---|
   | Цилиндрическая | Δ = −0,5·r<sub>cyl</sub> (табл. 4, 18; сноска 45: коэффициент 0,5 приблизителен) | Δ = −сдвиг из табл. 2 |
   | Плоскопараллельная | Δ = водоэквивалентная толщина окна (табл. 5): внутренняя поверхность окна | Δ = +сдвиг из табл. 3 за наружной поверхностью окна |

   Для камер, которых нет в таблицах Report 385, берётся сдвиг по TRS-398 со справкой: Report 385 такие камеры для референсной дозиметрии электронов не рекомендует. Формула R<sub>50</sub> по I<sub>50</sub> в Report 385 дана для 1,7 ≤ I<sub>50</sub> ≤ 10 см — вне этого диапазона при TG-51 выводится предупреждение. Детектор дозы — без сдвига, если он не введён вручную.
2. **I<sub>50</sub>** (R<sub>50,ion</sub>) — глубина, на которой ионизация за максимумом впервые падает до 50 % (линейная интерполяция между соседними точками). **R<sub>50</sub>** = 1,029·I<sub>50</sub> − 0,06 г/см² при I<sub>50</sub> ≤ 10 г/см², иначе 1,059·I<sub>50</sub> − 0,37 (TRS-398, ур. 37; TG-51, ур. 16–17; Report 385, ур. 3). Для детектора дозы R<sub>50</sub> — глубина 50 % самой кривой.
3. **Доза:** D(z) ∝ M(z)·s<sub>w,air</sub>(R<sub>50</sub>, z) (TRS-398 Rev.1, разд. 7.7.1), нормировка на максимум. s<sub>w,air</sub> — табл. 22 TRS-398 Rev.1 (R<sub>50</sub> = 1–10 г/см², z/R<sub>50</sub> = 0,02–1,2). По тексту разд. 7.7.1 значения первого издания пересмотрены с учётом ICRU 90 и признаны соответствующими новому значению I для воды; таблица получена по многопараметрическому выражению Burns, Ding, Rogers (Med. Phys. 23, 489, 1996; ссылка [173] TRS-398):

   s<sub>w,air</sub> = (a + b·x + c·x² + d·y) / (1 + e·x + f·x² + g·x³ + h·y), x = ln(R<sub>50</sub>/см), y = z/R<sub>50</sub>,

   a = 1,0752, b = −0,50867, c = 0,08867, d = −0,08402, e = −0,42806, f = 0,064627, g = 0,003085, h = −0,1246 (коэффициенты — Rogers, Med. Phys. 31, 3460, 2004). Калькулятор считает по этому выражению: оно воспроизводит все 350 значений табл. 22 в пределах округления (±0,0005) и строку s<sub>w,air</sub>(z<sub>ref</sub>) — это проверяет автотест (`tests/data/trs398_table22.json`). Ближе к поверхности (z/R<sub>50</sub> < 0,02) и в тормозном хвосте (z/R<sub>50</sub> > 1,2) берутся значения на краях таблицы (со справкой); при R<sub>50</sub> вне 1–10 г/см² — предупреждение. Изменение поправки на возмущение с глубиной не учитывается: у камер эталонного класса оно сдвигает R<sub>50</sub> меньше чем на 0,05 г/см² (разд. 7.7.1).
4. **Параметры кривой дозы:**
   - R<sub>100</sub> (z<sub>max</sub>) — вершина параболы, проведённой методом наименьших квадратов через непрерывный участок точек не ниже 98 % вокруг максимума (если парабола не подходит — точка максимума);
   - R<sub>90</sub>, R<sub>80</sub>, R<sub>50</sub> (по кривой дозы, для контроля) — глубины, где доза за максимумом падает до 90, 80 и 50 %;
   - R<sub>p</sub> (практический пробег; определение — ICRU Report 35, ссылка [19] TRS-398) — пересечение касательной к спаду с линией тормозного фона. Касательная — прямая по точкам спада от 70 до 30 % (участок у точки наибольшего спада почти прямой); фон — прямая по точкам глубже, чем касательная доходит до нуля, с запасом R<sub>0</sub> − R<sub>80</sub> (не меньше 2 мм); D<sub>x</sub> — фон на глубине R<sub>p</sub>. Если кривая заканчивается раньше фона, R<sub>p</sub> — пересечение касательной с нулём;
   - z<sub>ref</sub> = 0,6·R<sub>50</sub> − 0,1 г/см² (TRS-398, ур. 39; Report 385, ур. 2), PDD(z<sub>ref</sub>) — линейной интерполяцией по кривой дозы; E<sub>0</sub> ≈ 2,33·R<sub>50</sub> МэВ (TRS-398, сноска 39).
5. **Перенос во вкладку «Электроны»:** раздел 3 — R<sub>50,ion</sub> (способ «по глубине 50 % ионизации»; для детектора дозы — R<sub>50</sub>), раздел 8 — PDD(z<sub>ref</sub>) и z<sub>max</sub> = R<sub>100</sub>. Для пересчёта дозы на z<sub>max</sub> протоколы требуют клиническую кривую (ту, что в системе планирования); если перенесённая кривая ею не является, исправьте значения.

## Вывод

- Табло: R<sub>50</sub> и I<sub>50</sub>, z<sub>ref</sub> и PDD(z<sub>ref</sub>), R<sub>100</sub>, R<sub>80</sub>, R<sub>p</sub>, D<sub>x</sub>, E<sub>0</sub>; кнопка переноса.
- График (SVG): ионизация (пунктир) и доза в процентах от своего максимума по глубине точки измерения, метки z<sub>ref</sub>, R<sub>80</sub>, R<sub>50</sub>, R<sub>p</sub>, касательная и фон. При наведении — значения обеих кривых на ближайшей глубине.
- «Скачать кривую дозы (.csv)»: глубина точки измерения, см; ионизация, %; s<sub>w,air</sub>; PDD, % (разделитель — точка с запятой, десятичный — по языку интерфейса).
- Протокол текстом (с кривой через 0,5 см), PDF, сохранение данных (.json) — как на других вкладках.

## Проверки

- Ошибки: нет данных или меньше пяти точек; максимум в конце кривой (неверное направление глубины или единицы); кривая не опускается до 50 %; для камеры нет данных о сдвиге (другая камера без радиуса или толщины окна; плоскопараллельная камера без водного эквивалента окна в табл. 5 при TRS-398).
- Предупреждения: цилиндрическая камера при R<sub>50</sub> < 3 г/см²; отрицательные показания; опорная глубина вне измеренного диапазона.
- Справки: глубина 50 % на кривой дозы отличается от R<sub>50</sub> по ур. 37 больше чем на 1 мм; шаг на спаде больше 2 мм; кривая начинается глубже 3 мм; точки над поверхностью после сдвига; s<sub>w,air</sub> на краях диапазона; несколько кривых в файле.

## Ограничения

- Поправка на рекомбинацию по глубине — линейная по показанию (общая рекомбинация); при очень высокой дозе за импульс, где зависимость нелинейна, её нужно определять отдельно.
- Поправка на возмущение по глубине (для цилиндрических камер) не вводится.
- Пластиковые фантомы (пересчёт глубины) не поддерживаются — только вода.
