# Электроны: формулы, источники и проверки

Раздел «Электроны» считает поглощённую дозу в воде для клинических пучков электронов по TRS-398 Rev.1 (глава 7) и по TG-51 с аддендумом для электронов WGTG51 Report 385 (2024). Расчётное ядро — `src/core/electrons.js`, данные камер — `src/core/electron-chambers.js`, тесты — `tests/electrons.test.js`.

Для TG-51 используется формализм Report 385, а не исходный TG-51 1999 года: аддендум заменяет k′<sub>R50</sub>, k<sub>ecal</sub> и измеряемую поправку на градиент P<sup>Q</sup><sub>gr</sub> новыми данными Монте-Карло. По оценке авторов, доза на МЕ по аддендуму до ~2 % выше, чем по исходному протоколу.

## Качество пучка и опорная глубина

- R<sub>50</sub> — глубина 50 % дозы в воде при РИП 100 см и поле не меньше 10 × 10 см (TRS-398, разд. 7.3.1; Report 385, разд. 4).
- По глубине 50 % ионизации: R<sub>50</sub> = 1,029·R<sub>50,ion</sub> − 0,06 г/см² при R<sub>50,ion</sub> ≤ 10 г/см²; R<sub>50</sub> = 1,059·R<sub>50,ion</sub> − 0,37 г/см² при R<sub>50,ion</sub> > 10 г/см² (TRS-398, ур. 37; TG-51, ур. 16–17; Report 385, ур. 3 — для 1,7 ≤ I<sub>50</sub> ≤ 10 см). Можно ввести R<sub>50</sub> напрямую, если он измерен детектором, отвечающим дозе.
- z<sub>ref</sub> = d<sub>ref</sub> = 0,6·R<sub>50</sub> − 0,1 г/см² (TRS-398, ур. 39; Report 385, ур. 2).
- E₀ ≈ 2,33·R<sub>50</sub> МэВ выводится для справки (TRS-398, сноска 39).
- Подсказка к измерению кривой ионизации показывает сдвиг точки измерения для выбранной камеры: 0,5·r<sub>cyl</sub> по TRS-398 (табл. 4) и сдвиги Report 385 (табл. 2 для цилиндрических, табл. 3 для плоскопараллельных камер).

## Положение камеры на опорной глубине

Протоколы устанавливают цилиндрическую камеру по-разному:

| | TRS-398 Rev.1 (табл. 19) | Report 385 (разд. 4, 5.3) |
|---|---|---|
| Цилиндрическая | центр на 0,5·r<sub>cyl</sub> глубже z<sub>ref</sub> | центр на d<sub>ref</sub> без сдвига, градиент учтён в k<sub>Q</sub> = k′<sub>Q</sub>·k<sub>Qecal</sub> |
| Плоскопараллельная | внутренняя поверхность входного окна на z<sub>ref</sub> с учётом водоэквивалентной толщины окна (табл. 5) | точка на Δz (табл. 3) за наружной поверхностью окна — на d<sub>ref</sub> |

Калькулятор показывает положение камеры для выбранного протокола (раздел 3). Все показания — основные серии, контрольные измерения и показания после калибровки — снимают в положении по выбранному протоколу. У цилиндрической камеры положения по TRS-398 и Report 385 различаются (0,5·r<sub>cyl</sub>), поэтому показания, снятые для одного протокола, для другого не подходят.

## Поправки к показанию

k<sub>TP</sub>, k<sub>elec</sub>, k<sub>leak</sub> и поправки, которые лаборатория могла не внести, — как для фотонов. Особенности электронов:

- **Полярность.** В электронных пучках эффект полярности больше, чем в фотонных. Report 385 (прил. A, табл. A1) допускает для камеры эталонного класса до 2 % и требует измерять поправку; TRS-398 (табл. 3) задаёт для камер эталонного класса менее 0,4 %. Калькулятор выдаёт справку при |k<sub>pol</sub> − 1| > 0,4 % и предупреждение при > 2 %.
- **Рекомбинация.** Импульсный или импульсно-сканирующий пучок: TRS-398, ур. (13) с табл. 10 (или ур. 14); TG-51, ур. (12). Ограничения k<sub>s</sub> ≥ 1 и ≤ 1,05 проверяются по измеренному значению, допущение k<sub>pol</sub>(V₂) = k<sub>pol</sub>(V₁) — как для фотонов (см. [photons.md](photons.md)). В электронных пучках эффект полярности больше, поэтому при сомнениях k<sub>s</sub> стоит определить при обеих полярностях и сравнить (TRS-398, сноска 25).
- P<sub>rp</sub> (Report 385, ур. 9) принимается равным 1. Report 385 (разд. 8.4.2) отмечает, что однородность пучков электронов на d<sub>ref</sub> такая же, как у фотонов с выравнивающим фильтром.
- Поправки, которые лаборатория могла не внести (k<sub>pol,Q₀</sub>, k<sub>s,Q₀</sub>), относятся к калибровке в ⁶⁰Co. При перекрёстной калибровке они не применяются: коэффициент получен по полностью исправленным показаниям (TRS-398, ур. 41; Report 385, ур. 5). Для перекрёстно откалиброванной камеры TG-51 принимает P<sub>elec</sub> = 1 (разд. VII.B), калькулятор напоминает об этом.

## k<sub>Q</sub>

### TRS-398 Rev.1

D<sub>w,Q</sub> = M<sub>Q</sub>·N<sub>D,w,Q₀</sub>·k<sub>Q,Q₀</sub> (ур. 38).

- **Калибровка в ⁶⁰Co:** k<sub>Q</sub> — табл. 20, линейная интерполяция по R<sub>50</sub>, или аппроксимация прил. II, по которой таблица рассчитана: ур. (98) a + b·exp(−R<sub>50</sub>/c) для плоскопараллельных и ур. (99) a + b·R<sub>50</sub><sup>−c</sup> для цилиндрических камер, параметры в табл. 47. Оба значения показываются рядом с разницей в процентах. Данные есть для PTW 34001 Roos и IBA NACP-02 (R<sub>50</sub> = 1–10 г/см²) и для NE 2571, IBA FC65-G, Exradin A12, A19, PTW 30013, 30012 (3–10 г/см²). Для остальных камер TRS-398 требует калибровки в пучке электронов.
- **Перекрёстная калибровка** (разд. 7.6): вводится N<sub>D,w,Qcross</sub> рабочей камеры (ур. 41) и R<sub>50</sub> пучка, в котором её провели; k<sub>Q,Qcross</sub> = k<sub>Q,Qint</sub>/k<sub>Qcross,Qint</sub> (ур. 44) по табл. 21 (Q<sub>int</sub> = 7,5 г/см²) с линейной интерполяцией или по аппроксимации с параметрами табл. 48.
- **Вручную:** например, k<sub>Q,Q₀</sub> по ур. (40) при калибровке в лаборатории в пучках электронов.
- Ограничения: цилиндрические камеры — только при R<sub>50</sub> ≥ 3 г/см² (табл. 19); при R<sub>50</sub> < 1,4 г/см² — предупреждение: рекомендуются экспериментальные коэффициенты (табл. 20–21, прим. c); R<sub>50</sub> вне диапазона таблицы — ошибка.

### TG-51 с Report 385

D<sub>w</sub> = M·k′<sub>Q</sub>·k<sub>Qecal</sub>·N<sub>D,w</sub><sup>⁶⁰Co</sup> (ур. 4).

- k′<sub>Q</sub> для цилиндрических камер: a + b·R<sub>50</sub><sup>−c</sup> (ур. 7, табл. 5); для плоскопараллельных: a + b·exp(−R<sub>50</sub>/c) (ур. 8, табл. 7); 1,70 ≤ R<sub>50</sub> ≤ 8,70 см. Вне диапазона — ошибка (можно ввести k<sub>Q</sub> вручную).
- k<sub>Qecal</sub> — табл. 4 (цилиндрические) и табл. 6 (плоскопараллельные).
- **Перекрёстная калибровка** плоскопараллельной камеры по цилиндрической (разд. 5.3.2): вводится (k<sub>Qecal</sub>·N<sub>D,w</sub>)<sub>pp</sub> по ур. (5), доза — по ур. (6): D<sub>w</sub> = (M·k′<sub>Q</sub>)<sub>pp</sub>·(k<sub>Qecal</sub>·N<sub>D,w</sub>)<sub>pp</sub>. Для цилиндрической камеры этот путь в Report 385 не предусмотрен — ошибка.
- Камеры, которых нет в табл. 4–7 (PTW 30012, Sun Nuclear SNC350p и «другие»), Report 385 не рекомендует; для них TG-51 считается только с k<sub>Q</sub>, введённым вручную.

## Пересчёт на z<sub>max</sub>

D(z<sub>max</sub>) = D(z<sub>ref</sub>)/(PDD(z<sub>ref</sub>)/100) по клинической кривой глубинной дозы (TRS-398, разд. 7.4.3; Report 385, разд. 4; TG-51, разд. X.D). Ошибки в этом разделе не блокируют дозу на z<sub>ref</sub>.

Результат — в Гр на 100 МЕ (то же число, что сГр/МЕ), рядом доза за отпущенные МЕ в сГр и в Гр на z<sub>ref</sub> и на z<sub>max</sub>. Номинальный выход задаётся на z<sub>max</sub> (после пересчёта) или на опорной глубине; итог и отклонение от номинала показываются на выбранной глубине, без пересчёта — на опорной.

## Контрольные измерения

После основных серий (раздел 5) и, возможно, подстройки ускорителя снимают ещё три показания при обычной полярности и V₁ в том же положении камеры (раздел 7). Итоговая доза считается по ним с поправками из разделов 4–6 (k<sub>TP</sub>, k<sub>pol</sub>, k<sub>s</sub>, k<sub>Q</sub>; в TG-51 — P<sub>TP</sub>, P<sub>pol</sub>, P<sub>ion</sub>, k′<sub>Q</sub>·k<sub>Qecal</sub>), которые повторно не измеряют. Показания раздела 5 служат только для поправок; если контрольные измерения не введены, доза считается по показанию M₁ раздела 5, и это отмечается в результате и в протоколе. Если контрольные измерения введены, но в них ошибка, итог не показывается, пока её не исправить. Число МЕ может отличаться от раздела 5; изменение относительно раздела 5 считается по показанию на МЕ.


## Калибровка ускорителя (раздел 9)

Если итоговая доза (по контрольным измерениям, а без них — по M₁ раздела 5) отличается от номинального выхода больше допуска (по умолчанию ±2 %, задаётся в разделе 8) на той глубине, где задан номинал, после раздела 8 появляется раздел 9 «Требуется калибровка?» (примечания становятся разделом 10). При ответе «Да» вводятся три показания при V₁ и обычной полярности после калибровки (подстройки) ускорителя. Поправки берутся из разделов 4–6. Доза по этим показаниям становится итоговой, а доза до калибровки показывается для справки вместе с отклонением от номинала и от новой дозы. Если доза в допуске, раздел скрыт и его показания не учитываются.

## Проверки ввода

- РИП: не 100 см — предупреждение для TRS-398; вне 90–110 см — предупреждение для TG-51.
- Поле меньше 10 × 10 см — предупреждение.
- R<sub>50</sub> вне 0,3–15 г/см² — ошибка единиц; I<sub>50</sub> < 1,7 см — предупреждение для TG-51.
- Разброс показаний, утечка, k<sub>s</sub>/P<sub>ion</sub>, T₀/P₀, давление — как для фотонов.
- PDD(z<sub>ref</sub>) вне 50–100 % — ошибка.
- Доза на опорной глубине вне 0,3–2 Гр на 100 МЕ, отклонение от номинала больше допуска и больше 20 % — как для фотонов.
- TG-51: камера из списка без данных Report 385 с k<sub>Q</sub>, введённым вручную, — предупреждение и нестандартные условия (Report 385, разд. 6.6).

**Соответствие референсным условиям** показывается под итогом так же, как для фотонов. Отступления: РИП не 100 см (TRS-398) или вне 90–110 см (Report 385), поле меньше 10 × 10 см, утечка больше 0,1 %, эффект полярности больше 2 %, камера не из таблиц или без данных Report 385 (TG-51).

## Что сверяется автотестами

- **Аппроксимации TRS-398 (табл. 47–48)** воспроизводят табл. 20–21 во всех узлах в пределах 0,001 — это независимая проверка и таблиц, и параметров.
- **Табл. 20 и 21 TRS-398:** для каждой камеры, у которой есть обе таблицы, отношение k<sub>Q</sub>/k<sub>Q,Qint</sub> = k<sub>Qint</sub> постоянно во всех узлах (разброс < 0,0002), кроме одного узла PTW 30013 (см. ниже). Это проверяет перенос обеих таблиц. Табл. 21 даёт 1,000 при R<sub>50</sub> = 7,5 г/см², значения убывают с ростом R<sub>50</sub>.
- **Report 385:** k′<sub>Q</sub>(7,5 см) = 1 в пределах 0,002 для всех 17 камер — это проверяет перенос параметров a, b, c и выбор формы аппроксимации.
- R<sub>50</sub> по I<sub>50</sub> в обеих областях, z<sub>ref</sub>, разбор названия пучка, положения камер.
- Демонстрационный набор: доза по TRS-398 и по TG-51 совпадает с расчётом «вручную».
- Перекрёстная калибровка по TRS-398 и по TG-51; запрет перекрёстной калибровки цилиндрической камеры в Report 385.
- Ограничения: цилиндрическая камера при R<sub>50</sub> < 3 г/см² (TRS-398), диапазон Report 385, камеры без данных.
- Пороги k<sub>pol</sub>; незаполненная PDD не блокирует дозу на z<sub>ref</sub>.

## Замеченные особенности источников

1. **TRS-398 Rev.1, табл. 20, PTW 30013, R<sub>50</sub> = 3,0 г/см².** Отношение k<sub>Q</sub>/k<sub>Q,Qint</sub> в этом узле 0,9082, а во всех остальных узлах 0,9078–0,9079. Аппроксимация прил. II (табл. 47) даёт в этом узле 0,9292, отношение к табл. 21 — 0,9296, а напечатано 0,9300. По-видимому, это опечатка в таблице. В режиме «по таблице» оставлено напечатанное значение; оно выше аппроксимации примерно на 0,09 % (на 0,04 % выше значения, согласованного с табл. 21), только около R<sub>50</sub> = 3 г/см². Режим «по аппроксимации» этой особенности не имеет. Сверено по русскому переводу; английский оригинал не проверялся.
2. **Report 385, табл. 3, Exradin P11 и P11TW:** в Report 374 сдвиги этих двух камер были перепутаны между собой (1,4 и 1,7 мм); калькулятор берёт исправленные значения из Report 385.
3. **NE 2571: TRS-398 и Report 385 дают разные аппроксимации k<sub>Q,Qint</sub> (k′<sub>Q</sub>).** В TRS-398, табл. 48: a = 0,982, b = 0,113, c = 0,920; в Report 385, табл. 5: 0,977, 0,117, 0,817. Для остальных общих цилиндрических камер параметры совпадают. Это разные наборы данных, а не ошибка переноса; каждый протокол считается по своим.
4. **IBA PPC40 и Exradin A10: параметры табл. 48 TRS-398 и табл. 7 Report 385 немного расходятся.** PPC40: a = 0,984 (TRS-398) и 0,985 (Report 385); A10: b = 0,112 и 0,113. При этом сама табл. 21 TRS-398 лучше описывается параметрами Report 385 (среднеквадратичное отклонение 0,0003 против 0,0007 для PPC40 и 0,0002 против 0,0005 для A10). По-видимому, в табл. 48 (по крайней мере в русском переводе) округление или опечатка. Калькулятор берёт для каждого протокола его собственные значения. Для этих камер в табл. 20 нет k<sub>Q</sub> при калибровке в ⁶⁰Co, и аппроксимация табл. 48 используется только при перекрёстной калибровке. Там k<sub>Q,Qcross</sub> — отношение двух значений одной аппроксимации, поэтому смещение почти полностью сокращается; в режиме «по таблице» его нет вовсе.
5. **Внутренние несогласованности TRS-398 Rev.1, на расчёт не влияющие.** Табл. 19 допускает цилиндрические камеры при R<sub>50</sub> ≥ 3 г/см², а разд. 7.2.1, 7.3.2 и табл. 18 — при R<sub>50</sub> > 3 г/см²; калькулятор следует табл. 19, с которой согласуется начало табл. 20. В прил. II сказано о пяти цилиндрических камерах, а в табл. 20 и 47 их шесть. Для окна Exradin A10 в табл. 5 указаны 3,86 мг/см² и 0,05 мм каптона, что не согласуется между собой (0,05 мм каптона ≈ 7 мг/см²); на решение о втором наборе показаний для TG-51 это не влияет.

## Пока не реализовано

- Расчёт перекрёстной калибровки по показаниям опорной и рабочей камер (сейчас вводится готовый коэффициент).
- Пересчёт кривой ионизации в кривую дозы через s<sub>w,air</sub> (табл. 22 TRS-398).
- Нестандартные условия: пластиковые фантомы, выходные факторы, увеличенные РИП для тотального облучения кожи.
- Бюджет неопределённости (TRS-398, табл. 24–25; Report 385, табл. 8–9).
