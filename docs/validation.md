# Проверка на независимых данных

Кроме сверки с таблицами и примерами самих протоколов (см. «Что сверяется автотестами» в документах модулей), калькулятор проверяется на реальных калибровках, посчитанных независимо — в рабочих таблицах отделений, не связанных с калькулятором. Входные данные вводятся в калькулятор и результат сравнивается с независимым расчётом: каждый поправочный коэффициент и итоговая доза. Каждый такой набор данных становится автотестом и проверяется при каждом изменении кода. Данные в тестах обезличены: без учреждения, ФИО и заводских номеров.

РИП 100 см, поле 10×10 см, z<sub>ref</sub> = 10 см, N<sub>D,w</sub> = 0,0479 Гр/нКл, C = 1,008 (поправочный множитель из свидетельства — в калькуляторе k<sub>лаб</sub>), V₁/V₂ = 300/100 В, 100 МЕ. ## Бюджет неопределённости: Elekta Versa HD, 6 МВ, 20.08.2026

Эталон — бюджет отделения в Excel по TRS-398 Rev.1 (табл. 17) с собственными оценками: N<sub>D,w</sub> — U = 1,1 % (k = 2) из свидетельства; долговременная стабильность 0,2 % и установка стандартных условий 0,3 % — типовые; показания M<sub>Q</sub> — тип А по шести повторам (s/√3: доза — среднее трёх экспозиций); строка k<sub>i</sub> разложена на k<sub>TP</sub> (u(T), u(P): поверка приборов и расхождение двух приборов), k<sub>pol</sub> и k<sub>s</sub> (распространение по сериям показаний), k<sub>elec</sub> (±0,5 % из свидетельства электрометра, прямоугольное распределение), k<sub>vol</sub> = 1; k<sub>Q</sub> — 0,6 %.

| | u<sub>c</sub>, % | U (k = 2), % |
|---|---|---|
| Лист Excel | 0,940 | 1,880 |
| Калькулятор: те же значения строк (своё: M<sub>Q</sub> 0,0128 %, k<sub>i</sub> 0,3019 %) | 0,940 | 1,880 |
| Калькулятор: типовой бюджет табл. 17 + U из свидетельства | 0,986 | 1,97 |

Совпадение — до 10⁻¹² (проверено и через интерфейс вкладки «Неопределённость»). Раскрытие k<sub>i</sub> в калькуляторе (с версии 0.14.0) с теми же u(T), u(P), сериями показаний и k<sub>elec</sub> даёт k<sub>TP</sub> 0,086 %, k<sub>pol</sub> 0,009 % и k<sub>s</sub> 0,018 % листа и итог строки 0,302 %; с учётом разрешения электрометра 0,01 нКл (в листе одинаковые показания дают s = 0) k<sub>pol</sub> и k<sub>s</sub> немного больше. Разница с типовым бюджетом — две строки: «показания относительно монитора» (0,3 % в табл. 17 и 0,013 % в листе) и «k<sub>i</sub>» (0,3 % и 0,302 %).

Доза того же листа (k<sub>Q</sub> = 0,9876, k<sub>pol</sub> и k<sub>s</sub> по серии при 400 и 200 В, доза по отдельной серии из трёх экспозиций) совпадает до 0,0001 %. Замечание к входным данным: по табл. 16 TRS-398 Rev.1 (и по формуле самого листа) для PTW 30013 при TPR<sub>20,10</sub> = 0,6823 k<sub>Q</sub> = 0,9872; 0,9876 даёт дозу на 0,04 % выше.

## Ещё не проверено на независимых данных

- ⁶⁰Co (вкладка и журнал), ошибка таймера;
- перекрёстная калибровка (фотоны и электроны);
- TG-51 целиком (сейчас — только по примерам из самих протоколов и k<sub>Q</sub> Report 385);
- электроны с цилиндрической камерой;
- журнал: сеанс на весь аппарат и проверка выхода на реальных датах.

Новые наборы данных добавляются так же: протокол или рабочая таблица с независимым расчётом → ввод в калькулятор → сравнение по каждому коэффициенту → автотест.
