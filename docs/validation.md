# Проверка на независимых данных

Кроме сверки с таблицами и примерами самих протоколов (см. «Что сверяется автотестами» в документах модулей), калькулятор проверяется на реальных калибровках, посчитанных независимо — в рабочих таблицах отделений, не связанных с калькулятором. Входные данные вводятся в калькулятор и результат сравнивается с независимым расчётом: каждый поправочный коэффициент и итоговая доза. Каждый такой набор данных становится автотестом и проверяется при каждом изменении кода. Данные в тестах обезличены: без учреждения, ФИО и заводских номеров.
