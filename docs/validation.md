# Проверка на независимых данных

Кроме сверки с таблицами и примерами самих протоколов (см. «Что сверяется автотестами» в документах модулей), калькулятор проверяется на реальных калибровках, посчитанных независимо — в рабочих таблицах отделений, не связанных с калькулятором. Входные данные вводятся в калькулятор и результат сравнивается с независимым расчётом: каждый поправочный коэффициент и итоговая доза. Каждый такой набор данных становится автотестом и проверяется при каждом изменении кода. Данные в тестах обезличены: без учреждения, ФИО и заводских номеров.

## Varian TrueBeam, 30.06.2026

Эталон — протоколы отделения в Excel (свой шаблон): M<sub>Q</sub> = M₁·k<sub>TP</sub>·k<sub>elec</sub>·k<sub>pol</sub>·k<sub>s</sub>·k<sub>FFF</sub>·C, D<sub>w</sub>(z<sub>ref</sub>) = M<sub>Q</sub>·N<sub>D,w</sub>·k<sub>Q</sub>, D(d<sub>max</sub>) = D<sub>w</sub>(z<sub>ref</sub>)·100/PDD(10). РИП 100 см, поле 10×10 см, z<sub>ref</sub> = 10 см, N<sub>D,w</sub> = 0,0479 Гр/нКл, C = 1,008 (поправочный множитель из свидетельства — в калькуляторе k<sub>лаб</sub>), V₁/V₂ = 300/100 В, 100 МЕ. Данные введены и в расчётное ядро, и через интерфейс вкладки «МВ фотоны» (очистить лист, ввести поля как пользователь); результат совпадает. Сохранение в файл и повторное открытие дают тот же итог.

k<sub>TP</sub>: в листе абсолютный нуль 273,2, в TRS-398 Rev.1 (ур. 10) — 273,15. k<sub>s</sub>: в листе коэффициенты a₀, a₁, a₂ с другим числом знаков. На дозу оба различия не влияют (< 0,001 %).

В скобках во второй–четвёртой колонках — отличие от листа.

Выводы:

- С теми же k<sub>Q</sub> и k<sub>vol</sub>, что в листе, доза совпадает до 0,001 %: все поправки к показанию, пересчёт на d<sub>max</sub> и отклонение калькулятор считает так же.
- k<sub>Q</sub> листа — табличные значения TRS-398 для FC65-P: калькулятор по табл. 16 даёт те же числа (до 4-го знака). По формуле TRS-398 Rev.1 (выбор по умолчанию) k<sub>Q</sub> больше на 0,003–0,015 %.
- Пучки БВФ: в листе k<sub>FFF</sub> = 1,003 для обоих пучков. По TRS-398 Rev.1 k<sub>vol</sub> зависит от TPR<sub>20,10</sub> и длины полости камеры: для FC65-P (2,3 см) при РИД 110 см ур. (22) даёт 1,0014 для 6 МВ БВФ (TPR 0,632) и 1,0034 для 10 МВ БВФ (TPR 0,706), табл. 11 — 1,0017 и 1,0037. Отсюда расхождения −0,15 % и +0,05 %: это различие во входном k<sub>vol</sub>, а не в расчёте. Если 1,003 получено из измеренного профиля пучка, его можно ввести в калькулятор как «своё значение» или посчитать там же по профилю.

## Ещё не проверено на независимых данных

- ⁶⁰Co (вкладка и журнал), ошибка таймера;
- перекрёстная калибровка (фотоны и электроны);
- TG-51 целиком (сейчас — только по примерам из самих протоколов и k<sub>Q</sub> Report 385);
- электроны с цилиндрической камерой;
- журнал: сеанс на весь аппарат и проверка выхода на реальных датах.

Новые наборы данных добавляются так же: протокол или рабочая таблица с независимым расчётом → ввод в калькулятор → сравнение по каждому коэффициенту → автотест.
