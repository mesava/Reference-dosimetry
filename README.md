# Референсная дозиметрия

Веб-калькулятор для калибровки пучков лучевой терапии (⁶⁰Co, МВ фотоны и электроны), то есть для определения поглощённой дозы в воде в стандартных условиях, и инструменты вокруг неё — перекрёстная калибровка рабочей камеры и бюджет неопределённости (интерфейс на русском, есть английская версия). Протокол выбирается в шапке:

- **IAEA TRS-398 Rev.1** (Andreo et al., 2024);
- **AAPM TG-51** (Almond et al., 1999) с аддендумом для фотонов (McEwen et al., 2014), аддендумом для электронов WGTG51 Report 385 (Muir et al., 2024) и рекомендациями WGTG51 Report 374 (Muir et al., 2022) — реализация приведена для сравнения.

Онлайн: https://mesava.github.io/Reference-dosimetry/. Полные ссылки — в разделе [«Литература / References»](#литература--references).

## Зачем

Готовые калькуляторы TG-51 и TRS-398 существуют, но они англоязычные и обычно не показывают, откуда взяты формулы и коэффициенты. Здесь:

- интерфейс и замечания на русском, в терминах TRS-398: РИП, РИО, БВФ, МЕ; есть английская версия;
- у каждой поправки и каждого предупреждения указан источник: протокол, раздел, уравнение или таблица;
- коэффициенты k<sub>Q</sub> и формулы проверяются автотестами по таблицам самих протоколов и по рабочим книгам реальной калибровки (Elekta Versa HD: фотоны 6 и 10 МВ, 6 и 10 МВ БВФ; электроны 6–15 МэВ). Тесты не входят в калькулятор и на расчёт не влияют: они запускаются при каждом изменении кода и показывают, если результат разошёлся с проверенными значениями;
- ввод проверяется по требованиям протоколов: P<sub>ion</sub> > 1,05, фольга для пучков БВФ, диапазоны применимости k<sub>Q</sub>, единицы давления, правдоподобие дозы на МЕ и т. п.

## Что уже есть

Страница `index.html` с вкладками **⁶⁰Co**, **МВ фотоны**, **Электроны** и **Инструменты**. Переключатель протокола (TRS-398 Rev.1 или TG-51) общий для вкладок; выбранная вкладка, протокол и язык запоминаются. Данные формы при переключении протокола сохраняются (кроме электронов с цилиндрической камерой: положения камеры по двум протоколам различаются, и показания нужно снимать для выбранного).

**Порядок работы.** Показания основного раздела (обе полярности, рабочее и пониженное напряжение) служат для поправок k<sub>pol</sub> и k<sub>s</sub>. Поглощённая доза считается по заряду контрольных измерений; если их нет — по показанию M₁ основного раздела, с пометкой в результате и протоколе. Если контрольные измерения введены, но в них ошибка, итог не показывается, пока её не исправить. Если доза отличается от номинального выхода больше допуска (фотоны и электроны; по умолчанию ±2 %, допуск задаётся в разделе 8), появляется раздел «Требуется калибровка?»: после калибровки ускорителя вводятся новые показания, доза по ним становится итоговой, а доза до калибровки остаётся для справки.

**Во всех разделах:**

- рабочий лист — одна длинная страница со списком разделов слева: щелчок прокручивает к разделу, текущий раздел подсвечивается, у каждого видно состояние (заполнен, есть предупреждение, есть ошибка). На экране средней ширины список сворачивается в колонку с номерами, на телефоне открывается кнопкой в нижней строке;
- тема оформления в шапке: как в системе, светлая или тёмная (печать и PDF всегда светлые); на телефоне страница в одну колонку, итог — в нижней строке со ссылкой «к результату»;
- переключатель языка RU / EN в шапке: интерфейс, замечания расчёта, справки, протокол текстом и PDF; демонстрационный пример (вымышленные данные) — на языке интерфейса; если в «Примечаниях» остался его текст, над результатом появляется напоминание;
- числа можно вводить с точкой или запятой: после ввода они приводятся к разделителю языка интерфейса;
- справки по коэффициентам и величинам — по щелчку на обозначениях с пунктирным подчёркиванием (в том числе метод Яффе, TMR, ошибка таймера, г/см²);
- учреждение, сотрудники, электрометр и серийные номера запоминаются в браузере и выбираются из списка; у каждого раздела свой список аппаратов;
- температура воды вне 15–25 °C и относительная влажность вне 20–80 % подсвечиваются с рекомендацией не проводить измерения; влажность записывается в протокол;
- таблица поправок: все коэффициенты, среднее показание без поправок, исправленное показание и доза — по тому заряду, по которому она считается;
- фотоны и электроны: предупреждение, если доза на опорной глубине вне 0,3–2 Гр на 100 МЕ (почти всегда — ошибка в числе МЕ, например 50 вместо 500) или отклонение от номинала больше допуска и больше 20 %;
- под итогом — соответствие референсным условиям выбранного протокола: «отступлений не найдено» или «нестандартные условия» со списком причин (поле, глубина или РИП не по протоколу, камера не отвечает критериям эталонного класса или включена в TRS-398 только для БВФ, пучок БВФ выше 10 МВ, %dd(10) пучка БВФ без фольги, камера без данных Report 385 и т. п.); то же в протоколе и PDF;
- сохранение данных в файл (JSON) и загрузка, копирование данных и протокола текстом. В файл записываются версия калькулятора и итог; при открытии файла итог пересчитывается текущей версией и сверяется с сохранённым, расхождение показывается над результатом. Версия калькулятора указывается в протоколе и PDF;
- сохранение в PDF через окно печати: без колонтитулов браузера, после таблицы поправок — оговорка и строки «ФИО — подпись» по числу сотрудников;
- раздел «Литература» внизу страницы.

**⁶⁰Co:**

- D<sub>w</sub> = M · N<sub>D,w</sub> (k<sub>Q</sub> = 1); установка по РИП или РИК 80/100 см, z<sub>ref</sub> = 5 или 10 г/см², поле 10 × 10 см;
- поправки на температуру и давление, полярность, рекомбинацию в непрерывном пучке (TRS-398 ур. 13 или 16, TG-51 ур. 11), электрометр, утечку;
- камеры из TRS-398 Rev.1 и TG-51 (37 цилиндрических и 11 плоскопараллельных) или своя, список «Мои камеры»;
- ошибка таймера по серии облучений с разным временем (прямая M = Ṁ·(t + τ)), по сравнению «t против n·t/n», замер заряда при выдвинутом источнике, вручную или без учёта — с предупреждением;
- доза за облучение в сГр и Гр, мощность дозы в сГр/мин и Гр/мин на z<sub>ref</sub> и z<sub>max</sub> (через PDD или TMR); значение для сравнения — на z<sub>max</sub> или на опорной глубине;
- активность источника на дату измерения и сравнение с вводом в эксплуатацию или предыдущей калибровкой с поправкой на распад ⁶⁰Co.

Подробности — в [docs/cobalt.md](docs/cobalt.md).

**МВ фотоны:**

- поправки на температуру и давление, полярность, рекомбинацию (методом двух напряжений), электрометр, утечку; показания вводятся по ячейкам, среднее считается сразу;
- подсветка полей: k<sub>pol</sub> вне 1 ± 0,004, k<sub>s</sub> < 1 или > 1,05 и другие ошибки ввода;
- N<sub>D,w</sub> в Гр/нКл, сГр/нКл, мГр/нКл или Гр/Кл; поправочный множитель лаборатории k<sub>лаб</sub> (множитель K из протокола поверки ВНИИФТРИ, по умолчанию 1,000); поправки на полярность и рекомбинацию, если лаборатория их не вносила;
- геометрия: РИП 100 см, РИО 100 см или ручной ввод РИП, поля и глубины;
- качество пучка:
  - TG-51: %dd(10)<sub>x</sub> в открытом пучке, со свинцовой фольгой в 50 или 30 см, по промежуточной формуле;
  - TRS-398: TPR<sub>20,10</sub> по измерению на 20 и 10 см или через PDD(20)/PDD(10); для БВФ — дополнительная оценка по PDD(10);
  - по желанию — поправка на рекомбинацию по глубине для TPR<sub>20,10</sub> и %dd(10) (k<sub>s</sub> пропорционально показанию; TRS-398, разд. 4.4.3.4 e, 6.3.2) — для пучков БВФ;
- k<sub>Q</sub> по TRS-398 — по формуле (34) и по табл. 16 с интерполяцией, рядом для сравнения; или измеренный в лаборатории;
- база из 37 цилиндрических камер с k<sub>Q</sub> из аддендума TG-51 (2014), исходного TG-51 (1999) и TRS-398 Rev.1; своя камера с аналогом или параметрами a, b; список «Мои камеры»;
- поправка на усреднение по объёму k<sub>vol</sub> / P<sub>rp</sub> для пучков БВФ: по формуле (22), по табл. 11, по измеренному профилю (ур. 21) или своё значение;
- подсказка, сколько МЕ отпускать для пучков БВФ; результат всегда приводится к 100 МЕ;
- пересчёт на d<sub>max</sub> через PDD (РИП) или TMR (РИО), при РИО — по выбору и через PDD при РИП 90 см;
- результат в Гр на 100 МЕ (= сГр/МЕ) и доза за отпущенные МЕ в сГр и Гр на опорной глубине и на d<sub>max</sub>; номинальный выход — на d<sub>max</sub> или на опорной глубине (для аппаратов, которые калибруют на 10 см);
- раздел «Требуется калибровка?» при отклонении больше допуска (по умолчанию ±2 %);
- номинальная энергия и признак БВФ заполняются по названию пучка;
- рабочая камера, откалиброванная перекрёстно в клиническом пучке МВ фотонов: N<sub>D,w,Qcross</sub> и k<sub>Q,Qcross</sub> = k<sub>Q</sub>/k<sub>Qcross</sub> (TRS-398, разд. 4.5.2–4.5.3, ур. 30).

Формулы, источники данных, список проверок и найденные в документах опечатки описаны в [docs/photons.md](docs/photons.md).

**Электроны:**

**Инструменты — перекрёстная калибровка рабочей камеры по опорной камере, откалиброванной в ⁶⁰Co:**

- три пучка: ⁶⁰Co (TRS-398 ур. 25, 32, 36: N<sub>D,w</sub> = (M<sub>ref</sub>/M<sub>field</sub>)·N<sub>D,w</sub><sup>ref</sup>), клинический пучок МВ фотонов (ур. 27, k<sub>Q</sub> опорной камеры по TPR<sub>20,10</sub>, табл. 16) и электроны (ур. 41, табл. 20; TG-51 — Report 385, ур. 5). Для ⁶⁰Co и фотонов TG-51 перекрёстную калибровку не описывает — расчёт по TRS-398;
- пошагово: пучок и качество → опорная камера с N<sub>D,w</sub> в ⁶⁰Co (и k<sub>лаб</sub>) → рабочая камера → температура и давление → показания обеих камер (обе полярности, два напряжения) → коэффициент;
- замещение или установка «бок о бок» с перестановкой, нормировка на внешний монитор (TRS-398, разд. 6.6), k<sub>vol</sub> обеих камер в пучке БВФ, свои T и P для рабочей камеры; положение камер для выбранного пучка и протокола;
- кнопка переноса заполняет раздел «Камера и электрометр» нужной вкладки: ⁶⁰Co → вкладки «⁶⁰Co» и «МВ фотоны» (N<sub>D,w</sub> в ⁶⁰Co); фотоны → «МВ фотоны» (N<sub>D,w,Qcross</sub> и TPR<sub>20,10</sub>, дальше k<sub>Q,Qcross</sub> = k<sub>Q</sub>/k<sub>Qcross</sub>, ур. 30); электроны → «Электроны»;
- сохранение, протокол текстом и PDF — как на других вкладках.

Подробности — в [docs/tools.md](docs/tools.md).

**Инструменты — неопределённость поглощённой дозы:**

- отдельный подраздел вкладки «Инструменты» (переключатель над рабочим листом; вкладка в шапке открывает подраздел, с которым работали последним); страницы дозиметрии бюджет не показывают;
- в начале каждого подраздела «Инструментов» — короткий ответ «Когда / Что делать / Результат» (куда идёт результат) и блок «Как проводить и как считается»: что откуда берётся и формулы по шагам;
- типовой бюджет из протокола выбирается по пучку, протоколу, типу камеры и способу её калибровки: TRS-398 табл. 13, 17, 24; аддендум TG-51 табл. II и Report 385 табл. 8, 9 (примеры (i) и (ii)); итоги типовых бюджетов совпадают с таблицами (тест);
- у каждой строки — откуда взять значение и ссылка; своё значение заменяет типовое; U из свидетельства о калибровке заменяет лабораторную часть; повторяемость серии показаний (тип А) сравнивается с табличной оценкой;
- рабочая камера после перекрёстной калибровки: строка 0,6 % (в квадратуре она увеличивает u<sub>c</sub> примерно на 0,2 %, как оценивает TRS-398, разд. 5.7 и 6.8); для электронов — типовые бюджеты для перекрёстно откалиброванной камеры;
- кнопки «Взять данные с вкладки ⁶⁰Co / МВ фотоны / Электроны»: пучок, тип камеры, способ калибровки, R<sub>50</sub>, показания, результат дозиметрии и сведения об аппарате;
- u<sub>c</sub>, U (k = 2) в процентах и в единицах дозы; протокол текстом, PDF, сохранение — как на других вкладках.

**Инструменты — график Яффе (ввод в эксплуатацию системы камера — кабель — электрометр):**

- показания при 6–8 напряжениях (по желанию — и при обратной полярности) → график 1/M от 1/V или 1/V² в SVG, прямая по линейной области, M<sub>нас</sub> и k<sub>s</sub> = M<sub>нас</sub>/M₁ (TRS-398 ур. 15; P<sub>ion</sub> — Report 374, прил. A);
- линейная область находится автоматически (допуск по отклонению от прямой) или выбирается вручную; V<sub>max</sub> — начало умножения заряда, предупреждения, если рабочее напряжение или напряжение производителя выше него;
- сравнение с методом двух напряжений при тех же V₁, V₂ (TRS-398 ур. 13, 14, 16; TG-51 ур. 11, 12), k<sub>s</sub> при обратной полярности и k<sub>pol</sub> для каждой точки;
- рекомбинация при разных мощностях дозы: метод двух напряжений для каждого условия и обобщённый подход ди Алмейды и Ниателя (TRS-398, ур. 17) — прямая M₁/M₂ от M₁, k<sub>s</sub> для любого показания; для ускорителей — k<sub>s</sub> = 1 + C<sub>init</sub> + C<sub>gen</sub>·D<sub>pp</sub> (аддендум TG-51, ур. 2), начальная рекомбинация и линейность; начальную рекомбинацию забирают поправки на рекомбинацию по глубине (МВ фотоны, кривая дозы электронов);
- сводка проверок по критериям камеры эталонного класса (TRS-398 табл. 3, аддендум TG-51 табл. III) со ссылками; протокол текстом, PDF, сохранение — как на других вкладках.

Подробности — в [docs/jaffe.md](docs/jaffe.md).

**Инструменты — кривая дозы электронов (пересчёт кривой ионизации):**

- вставка двух столбцов из экспорта сканера или файл (CSV, TXT, PTW .mcc); камера из списка для электронов, другая камера или детектор дозы;
- сдвиг к точке измерения по протоколу: TRS-398 — 0,5·r<sub>cyl</sub> или водный эквивалент окна (табл. 4, 5), Report 385 — сдвиги камер (табл. 2, 3); можно ввести вручную;
- I<sub>50</sub> → R<sub>50</sub> (TRS-398 ур. 37), доза = ионизация × s<sub>w,air</sub>(R<sub>50</sub>, z) (TRS-398, разд. 7.7.1, табл. 22 — по выражению Burns et al., которое воспроизводит все 350 значений таблицы; тест);
- по желанию — поправки по глубине на рекомбинацию (k<sub>s</sub> пропорционально показанию, TRS-398 разд. 7.3.2, сноска 46; k<sub>s</sub> на опорной глубине — из вкладки «Электроны», C<sub>init</sub> — из «Графика Яффе») и на полярность (по кривой при обратной полярности); их влияние на I<sub>50</sub> и PDD(z<sub>ref</sub>) показывается;
- R<sub>100</sub>, R<sub>90</sub>, R<sub>80</sub>, R<sub>50</sub>, R<sub>p</sub>, D<sub>x</sub>, z<sub>ref</sub>, PDD(z<sub>ref</sub>), E<sub>0</sub>; график ионизации и дозы с подсказками при наведении; кривая дозы в CSV;
- кнопка переноса заполняет во вкладке «Электроны» R<sub>50,ion</sub>, PDD(z<sub>ref</sub>) и z<sub>max</sub>.

Подробности — в [docs/edepth.md](docs/edepth.md).

## Как пользоваться

- **Онлайн:** https://mesava.github.io/Reference-dosimetry/ (GitHub Pages; страница обновляется автоматически после изменений в ветке `main`). Файлы, сохранённые до отказа от режима «Оба», открываются по TRS-398.
- **Без интернета:** файл [`dist/index.html`](dist/index.html) — это весь калькулятор в одном файле. Его можно скачать и открыть двойным щелчком. Без интернета шрифты заменятся системными, расчёт работает так же.
- **Из исходников:** страница использует ES-модули, поэтому `index.html` из корня нужно открывать через локальный сервер, а не двойным щелчком:
  ```
  python3 -m http.server 8000
  ```
  затем открыть http://localhost:8000.

Все расчёты выполняются в браузере, данные никуда не отправляются. Черновики форм, выбранные вкладка, протокол и язык, списки учреждений, аппаратов, пучков, сотрудников, электрометров и серийных номеров, а также «Мои камеры» хранятся только в этом браузере (localStorage): на другом компьютере или в другом браузере их не будет. Чтобы перенести измерения, сохраните их в файл (JSON) и откройте на другом устройстве.

## Для разработки

Нужен Node.js 18 или новее.

```
npm install        # esbuild для сборки, acorn для проверки переводов
npm test           # автотесты
npm run build      # пересобрать dist/index.html
npm run i18n:check # у каждой русской строки в JS есть английская пара L('…', '…')
```

`dist/index.html` хранится в репозитории: после изменений его нужно пересобрать и закоммитить. При выпуске новой версии меняют `src/core/version.js` и `version` в `package.json` (их совпадение проверяет тест). GitHub Actions при каждом изменении запускает тесты, проверку переводов и проверяет, что `dist/index.html` собран из текущих исходников.

## Планы

По важности и объёму:

1. **Ежедневная работа:** профили оборудования (камеры, электрометры, N<sub>D,w</sub> и сроки поверки; аппараты с пучками, номиналами, PDD/TMR) → сеанс на весь аппарат с общим протоколом → журнал калибровок и тренд выхода.
2. **kV-рентген по TRS-398 Rev.1** — отдельный большой модуль (воспроизводимость, линейность, СПО и др.).
3. **Брахитерапия:** источники ⁶⁰Co и ¹⁹²Ir, колодезная камера и фантом PTW 9193.
